# Short Bus Hybrid Demo (unlisted)

Playable one-track demo: Ra Tod's Short Bus as the player vehicle on the Sunset Bay Circuit (3 laps, 8 racers), built on the Kart Royale codebase (MIT — see LICENSE, Copyright (c) 2026 Ryan Campbell) with a new procedural Short Bus model, bus physics/collision, and Ra Tod branding.

Unlisted working copy for Ra's preview only — not linked from the public Ra Tod Musik website. Rival karts are placeholders; competitor models come later.

Controls: Enter to start, arrow keys / WASD to drive, Shift to drift, Space for item, Esc to pause. Touch controls on mobile.
